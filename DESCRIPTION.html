Extra random drops from blocks, mobs and Pokémon, all set up in one config file.
By default mined stone drops ores. See Default config if your world still has normal ores.
Made for my Nekoro Pokemon modpack, but it works with any items from any mod.

Required on the server. Optional on the client, where it adds the JEI tab.

Features

Default config

  • Mined stone and deepslate drop coal, iron, copper, gold, redstone, lapis, diamonds and emeralds about as often as vanilla ore generation would give them at that height, plus amethyst, quartz and a tiny chance of netherite scrap.
  • Deepslate drops twice as often, and below Y 0 every kind can drop.
  • Emeralds are more common in mountains and gold in badlands.
  • The right pickaxe tier is needed, like for real ores.
  • This is meant for worlds without ores, for example with ore removal in Nekoro World Setup. If your world still generates ores, delete these rules or you get ores twice.

Rules

  • Drops from mined blocks and killed mobs, by id or by tag.
  • Any chance, from always to 0.001% and lower.
  • Items, experience or both. Experience comes as orbs, so Mending works.
  • Fortune and Looting work at any level, also modded levels up to 255.
  • No drops with Silk Touch, unless you allow it for a rule or let its level raise the chance.
  • A rule can need a tool of a set tier, like mining an ore.
  • Drop on the ground or straight into the inventory.
  • A cooldown per player.
  • Limit a rule to a height, dimension or biome, checked at the exact block.
  • Every rule rolls on its own.

Cobblemon

  • With Cobblemon installed, rules can reward defeated and caught Pokémon, by type or by species.
  • Defeated means killed or beaten in battle.
  • A Fire/Flying Pokémon rolls for both types.
  • Cobblemon is optional. It has no Forge 1.21.1 version, so these rules do nothing there.

JEI tab

  • With JEI installed, a Random Drop tab shows every rule: look up an item to see where it drops and how often.
  • The tab is built from the player's own copy of the config, so modpacks should ship the config.

More information

Config

  • All rules are in config/Nekoro/random_drop.json.
  • The file explains every option and has commented examples, including the setup of my modpack. Remove the // in front of a line to turn it on.

A 2% chance of flint from any stone, a 0.2% chance of a diamond from deepslate below Y -40, and a 0.5% chance of a coin from every Fire Pokémon you defeat in the Nether:

{
  "rules": [
    { "source": "block", "match": "#c:stones", "item": "minecraft:flint", "chance": 0.02 },
    { "source": "block", "match": "minecraft:deepslate", "item": "minecraft:diamond", "chance": 0.002, "max_y": -40 },
    { "source": "pokemon_kill", "type": "fire", "item": "nekorocoins:coin041", "chance": 0.005, "dimension": "minecraft:the_nether" }
  ]
}

Commands

  • /randomdrop reload: load the config again without restarting. /reload does it too and also refreshes the JEI tab.
  • /randomdrop list: show all active rules.
  • Both need operator permissions.
