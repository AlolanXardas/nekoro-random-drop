Extra random drops from blocks and mobs, all set up in one config file.
With Cobblemon installed it can also reward defeated and caught Pokémon, but Cobblemon is not required.
Made mainly for my Nekoro Pokemon modpack, but it works with any items from any mod.

The config starts empty

Out of the box this mod does nothing. You add your own rules in config/nekoro_random_drop.json.
The file explains every option and has commented examples, including the setup my modpack uses. Remove the // in front of a line to turn it on.

Features

• Drops from mined blocks and from killed mobs, by id or by tag (e.g. #c:stones)
• Any chance, from always to 0.001% and lower
• Items, experience or both
• Fortune and Looting work at any level, also modded levels up to 255
• No drops with Silk Touch, unless you allow it for a rule
• Drop on the ground or put straight into the player’s inventory
• Cooldown per player, e.g. one reward every few ticks while mining
• Limit a rule to a height range, a dimension or a biome (biome tags work too), checked at the exact block, so a rule for Lush Caves works only in the cave
• Cobblemon: rules for defeated (killed or beaten in battle) and caught Pokémon, by type or by species
• Every rule rolls on its own, so a Fire/Flying Pokémon rolls for both types
• With JEI installed, a Random Drop tab shows every rule: look up an item to see where it drops and how often

Example

A 2% chance of flint from any stone, a 0.2% chance of a diamond from deepslate below Y -40, and a 0.5% chance of a coin from every Fire Pokémon you defeat in the Nether:

{
  "rules": [
    { "source": "block", "match": "#c:stones", "item": "minecraft:flint", "chance": 0.02 },
    { "source": "block", "match": "minecraft:deepslate", "item": "minecraft:diamond", "chance": 0.002, "max_y": -40 },
    { "source": "pokemon_kill", "type": "fire", "item": "nekorocoins:coin041", "chance": 0.005, "dimension": "minecraft:the_nether" }
  ]
}

Commands

/randomdrop reload – load the config again without restarting (/reload does it too and also refreshes the JEI tab)
/randomdrop list – show all active rules
Both need operator permissions.

Requires

Minecraft 1.21.1: NeoForge, Forge or Fabric
Minecraft 1.20.1: Forge (also works on NeoForge 1.20.1), Fabric or Quilt
Fabric and Quilt also need Fabric API (QFAPI on Quilt)
Cobblemon (1.8+ on 1.21.1, 1.5+ on 1.20.1) and JEI are optional
Cobblemon has no Forge 1.21.1 version, so Pokémon rules do nothing there

Drops work with the mod on the server only. Players who also have it (and JEI) see the Random Drop tab, built from their own copy of the config file, so modpacks should ship the config.
